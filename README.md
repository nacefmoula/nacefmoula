## 🌟 Featured Projects

### 🎯 InterviewPrep TN — Cloud-Native Interview Prep Platform
> End-to-end DevOps showcase: from bare OpenStack VMs to a production-grade microservices stack on Kubernetes.

- **🏗️ IaC:** Provisioned the full infrastructure on OpenStack with **Heat templates**, configured servers automatically with **Ansible**.
- **🔁 CI/CD:** Built multi-stage **GitHub Actions** pipelines for build, test, image push, and deploy.
- **🐳 Orchestration:** Containerized services with **Docker**, deployed to a **Kubernetes** cluster.
- **🧩 Architecture:** Spring Boot microservices, **Kafka** for async messaging, **Redis** for caching, **Keycloak/OAuth2** for centralized identity.
- **🌐 Edge & Security:** **Cloudflare** for DNS, proxy, and HTTPS termination.

`Spring Boot` · `Angular` · `Docker` · `Kubernetes` · `OpenStack` · `Ansible` · `GitHub Actions` · `Kafka` · `Redis` · `Keycloak` · `Cloudflare` · `PostgreSQL`
